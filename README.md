WOK RUSH is a fast-paced, high-juice wok cooking and order-assembly arcade game built for the make.fun cooking game bounty. Race against ticking patience timers to chop, toss, assemble, and serve authentic street food dishes like Nasi Goreng, Mie Ayam, and Sate before impatient customers walk out! Featuring responsive Canvas 2D vector art, dynamic WebAudio sound effects and procedural music, combo multipliers, screen shake feedback, and instant restart arcade action.

Play on [make.fun](https://make.fun).
